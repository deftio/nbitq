# nbitq documentation

These pages are the long-form documentation for nbitq. The
[README](../README.md) at the repository root is the short version; start
there if you have not already.

| Page | Read it when |
|---|---|
| [What nbitq is](what-is-nbitq.md) | You want to know whether it solves your problem, and who else uses this kind of thing |
| [Getting started](getting-started.md) | You are ready to copy the files in and write the first call |
| [How it works](how-it-works.md) | You want to know exactly which bit goes where, with worked examples down to the byte |
| [API reference](api-reference.md) | You know what you want and need the signature |

The same material is published as a website at
<https://deftio.github.io/nbitq/>. The site is built from the static pages in
[`../pages/`](../pages/); the Markdown here is the source of record and the
two are kept in step by hand.

Every byte value and bit count in these pages was produced by running the
library. If you find one that is wrong, that is a bug; please
[report it](https://github.com/deftio/nbitq/issues).
